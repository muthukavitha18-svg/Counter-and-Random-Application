📌 Project Description

This project is a React-based application that includes two mini features:

• Counter Application
• Random Number Generator

The app demonstrates how to manage and update state dynamically using the useState hook, along with event handling and conditional rendering.

🎯 Objective

Build a multi-feature React app focusing on:

• useState hook usage
• Event handling
• Conditional rendering
• Component-based structure
• Clean UI design

🔑 Key Features
🔢 Counter Application

• Increment, Decrement, Reset functionality
• Prevents negative values (optional)
• Displays real-time count

⚠️ Conditional Message

👉 “Minimum limit reached” when count is 0

🎲 Random Number Generator

• Generates number between 1–100
• Updates instantly on button click

⚠️ Conditional Message

👉 “No number generated yet” before first click

🔁 Dynamic UI Updates

• State change → UI immediately update ஆகும்
• React re-render concept clear ah puriyum

🎨 Clean UI Design

• Separate sections for each feature
• Center aligned layout
• Simple and user-friendly interface

🧠 State Management

• useState used for:

Counter value
Random number

• Each feature has independent state

🧩 Component Structure

• App.js → Main container
• Counter component (optional split)
• Random component (optional split)

👉 Better practice: separate components use pannalam
